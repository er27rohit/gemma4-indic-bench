# gemma4-indic-bench
A high-performance inference benchmarking suite for Google's Gemma 4 (E2B/E4B) models, specifically targeting Indic language performance (Hindi/English).

## Objective
Evaluate latency, throughput, and quantization trade-offs for on-device AI applications in the Delhi NCR context.

## Stack
- **Engine:** vLLM / llama.cpp
- **Models:** Gemma 4 E2B-IT, Gemma 4 E4B-IT
- **Hardware:** Kaggle T4 GPUs (Simulating edge constraints)
